# Лаборатория обществ

Симуляция без игрока: остров посреди моря, в год 0 к берегу пристают лодки с первыми семьями — а дальше всё само. Люди ищут воду и еду, строят деревни по плану вдоль улицы, протаптывают дороги, роют колодцы, ловят рыбу, пасут коз, женятся, рожают детей, болеют, ссорятся, воюют, мстят за родичей, бегут с любимыми и уплывают, когда на острове тесно. Из простых правил вырастают вождества, государства и человеческие судьбы.

**Открыть:** https://kirgoncharov-eng.github.io/society-simulator/ (последняя принятая версия) или скачайте [`dist/index.html`](dist/index.html) и откройте в браузере (один файл, работает без сервера). Онлайн-версия: https://claude.ai/artifact/M3QAWrGEyimwpruzzKnPyw

[Миссия проекта](docs/MISSION.md) описывает, каким мы хотим увидеть этот мир и почему важно показать, как решения людей меняют остров.
