# Архитектура

## Сборка
```
src/engine/*.js  ─┐  склейка по номеру → const SIM = (() => { … return {…} })();  → dist/sim.cjs
src/ui/*.js      ─┼─ склейка по номеру → { … }  (один блок <script>)
src/ui/atlas-data.json ─ готовый атлас 100 миров (посчитан на старой «материковой» модели)
src/index.template.html ─ разметка, стили, места /*SIM*/ /*UI*/ /*ATLAS*/[]  → dist/index.html
```
`tools/build.mjs` ничего не транспилирует: это простая склейка текста. Значит, все функции движка лежат в одной области видимости, порядок файлов важен только для `const`/`let` верхнего уровня, которые используются при загрузке (`SYL`, `N`, `CS`, таблицы). Публичный API — `return { … }` в конце `src/engine/63-yearly.js`:

```js
SIM.newWorld(seed, params) → S      // новый мир-остров
SIM.step(S)                         // один день (тик); 360 тиков = год
SIM.shock(S, kind)                  // вмешательство: мор, засуха, набег…
SIM.serialize(S) / SIM.restore(obj) // сохранение
SIM.date(S), SIM.key(a,b), SIM.gini(arr), SIM.regime(S,g), SIM.landTop(S), SIM.popOf(S), SIM.kin(S,a,b), SIM.kidsOf(S,a), SIM.groupName(S,g)
```

## Время
`step` — день. Внутри: движение и работа каждого человека (`move`, `interact`, `produce`, `lifecycle`), раз в 30 тиков `monthly` (группы, вода, война, торговля, мор, судьбы), раз в 360 — `yearly` (дороги, тесноты, засуха, эпоха, атлас-снимок). Сезон: `seasonOf(S)`, зима — тики 12–78 по льду.

## Состояние `S` (главное)
- `S.rng` — генератор, единственный источник случайности. `S.tick` — день.
- `S.agents` — живые взрослые: `id name x y age life sex spouse mother father group role job energy wealth status skill rep trust patron bio drama …`.
- `S.kids` — дети до 15 лет (вне карты, едят из запасов деревни), растут в `growUp`.
- `S.groups` — деревни и кочевые общины: `members leader home(x,y) store(stock) gov faith take lord treasury well fboats goats pasture …`.
- `S.nodes` — ресурсы на земле: угодья, лес, рыба у берега (`kind:'fish'`), каменоломни.
- Карта: `S.ter` (50×50 клеток по 20 px: `s` море, `b` пляж, `w` река, `h` холм, `f` лес, `g` трава), `S.wood`, `S.ford`, `S.bridge`, `S.wear`/`S.road` (протоптанность → дороги), `S.frozen`, `S.springs`, `S.isle` (центр и радиус острова), `S.river`.
- Война и политика: `S.wars`, `S.hostility`, `S.alliances`, `S.states`, `S.truce`.
- История: `S.events` (лента для людей, `{t,type,text,…}`), `S.legends` (архив судеб), `S.stats` (счётчики: births, childDeaths, death, sick, burnout=голод, war, plague, drown, lostAtSea, killed, coups, wars…).

## Карта модулей движка
| файл | что внутри |
|---|---|
| 00-core | имена, `rnd/gauss/pick`, `clamp`, `dist`, индекс, `log` (событие в ленту); связанная летопись: `log` (с `causes`), `note`, `cite`, `eventById`, архив `S.evArch` и `archiveGC` |
| 10-island | лодки (`landBoat`, `beachSpot`), рыбные сектора моря, `spawnBand` |
| 20-world | `newWorld`, `spawn` (человек/ребёнок/переселенец), `join/leave`, группы, лидеры, наследование власти, `pickTarget` |
| 30-terrain | сетка `N×N`, `genTerrain` (береговая линия, холмы, река, лес) |
| 31-navigation | `passCost`, A* с кучей, кэш путей, компоненты связности `reach`, `toLand` (выталкивает из воды), утопления, дороги, мосты, план деревни |
| 32-settlement | оседание, место дома/поля, стройки, носка грузов (`HAUL`, `deliver`) |
| 40-jobs | распределение работ (поле, лес, камень, вода, рыба, пастух, ремесленник, стража, купец) |
| 41-trade | товары, цены, караваны, набеги на склады |
| 42-war | угроза, оборона, решение о войне, переговоры и откуп (`parley`), поход, битва, дань |
| 43-territory | владения клеток, межи, патрули |
| 44-institutions | монета, вече, долги, кабала |
| 46-hamlets | хутора, ватаги и одиночки перебираются в деревни (`hamletsMonth`, `absorb`), масштабный стресс раскола (`fissionP`), дочерние деревни (`bud`) |
| 50-water | родники, колодцы, водоносы, засуха, грязная вода |
| 51-fates | летопись `bio`, вес драмы `BW`, месть, побег влюблённых, легенды |
| 52-people | родство, браки, дети, взросление, мор, теснота, подражание |
| 53-bonds | личные связи с причиной: `bond`, `bondW`, затухание и дружба (`bondsMonth`), наследование (`inheritBonds`), побратимы, друзья детства, рыбаки одной лодки |
| 54-households | семья и дом: `familiesOf`, `householdsMonth` (кто где живёт, наследство дома, ветшание), `houseOwnerDies`, `housemates` для карточки |
| 55-customs | споры и обычаи: `ruling`, `setCustom`, спор наследников (`inheritDispute`), месть или вира (`bloodOrWergild`, `bloodShed`), распространение обычаев (`customsYear`) |
| 55-daily-rhythm | длина светового дня, путь до дома или ночлега, положение человека в выбранный час |
| 60-step | `step`, `move`, `interact`, `produce`, `lifecycle` (смерть по причинам), `removeAgent` |
| 61-monthly | месяц деревни: еда, доли, переворот, обиды; помощь голодной деревне (`aidMonth`) |
| 62-politics | власть, отношения, слияние, покровительство, государства, строй (`regime`) |
| 63-yearly | год, эпохи, `gini`, `shock`, `serialize/restore`, публичный API |

## Карта модулей UI
| файл | что внутри |
|---|---|
| 00-state | состояние страницы, цвета, подписи работ, `world()` (создание мира) |

| 19-daily-rhythm | часы «Сутки», сумерки и общие позиции жителей для карты и 3D |
| 20-map2d | 2D-карта: море, остров, река, владения, лодки, огороды, козы, дороги, дома, люди (`draw`) |
| 30-charts | общества, портреты деревень, рынок, «Река истории» |
| 40-panels | правая панель, карточка человека (`card`) |
| 50-experiment | режим «два мира» с разными вводными |
| 60-view3d | 3D на three.js r128 (InstancedMesh, камера, полёт к деревне) |
| 70-atlas / 71-atlas-runner | атлас 100 миров; пересчёт в Web Workers (`ATLW` — код воркера строкой; `MODEL_V` = `SIM.MODEL.v` — версия модели для кэша в localStorage) |
| 80-fates | вкладка «Судьбы», слежение камерой |
| 90-main | главный цикл `frame`, запуск |

Отладка в браузере: `__lab()` возвращает текущий `S`, `SIM` доступен глобально.

## Куда идёт «красивый движок»
План: оставить движок как есть и написать новый рендер, который только читает `S` каждый кадр (позиции людей, дома, поля, сезон, погода). Рендер не должен менять `S`. Хорошая граница — модуль `src/ui/60-view3d.js`: новый движок может заменить его целиком.
